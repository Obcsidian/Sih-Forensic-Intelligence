# Sample Case

Synthetic demo data generated by `scripts/seed_demo_case.py`. Contacts, calls,
messages and device events are fully synthetic and safe to demo publicly.

`photos/` and `audio/` are intentionally empty — drop your own image/audio files
in to exercise face clustering and transcription. Everything else (timeline,
relationship graph, anomaly detection, reporting) works from the CSV/JSON alone.

Ingest this case via the API:

```
POST /cases            {"name": "Sample Case", "source_path": "<absolute path to this folder>"}
POST /cases/{id}/ingest
```
